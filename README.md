# Sales Analysis

## Project Overview

This project focuses on analyzing transactional retail sales data using **SQL and Metabase** to understand revenue performance, customer behavior, product trends, and operational metrics across multiple geographies.

Advanced SQL techniques were used to transform transactional data into business-ready datasets, while Metabase was used to build interactive dashboards for KPI monitoring and business analysis.

## Objectives

* Analyze retail sales performance across different geographies.
* Understand customer purchasing behavior.
* Identify product and revenue trends.
* Monitor important business KPIs.
* Build interactive dashboards for stakeholder reporting.
* Generate insights to support business decision-making.

## Analysis Workflow

```text
Raw Transactional Data
          ↓
Data Cleaning & Validation
          ↓
SQL Transformations
          ↓
Business Metrics & KPIs
          ↓
Customer/Product Analysis
          ↓
Metabase Dashboards
          ↓
Business Insights
```

## SQL Analysis

Advanced SQL concepts were used for data transformation and analysis, including:

* Joins
* CTEs
* Window Functions
* Aggregations
* Subqueries
* Conditional logic
* Date-based analysis

Data quality checks were also performed to identify missing, inconsistent, and invalid transactional records.

## Key KPIs

* Revenue
* Average Order Value (AOV)
* Customer Retention Rate
* Repeat Customer Percentage
* Order Volume
* Cancellation Rate

## Key Analysis Areas

### Customer Analysis

* Repeat purchasing behavior.
* Customer retention.
* Customer segmentation.
* High-value customer identification.

### Product Analysis

* Product performance.
* Revenue contribution.
* Product-level trends.

### Geographic Analysis

* Sales performance across countries.
* Revenue trends by geography.

### Time-Based Analysis

* Sales trends across different time periods.
* Changes in customer and revenue performance.

## Dashboard

Interactive Metabase dashboards were developed with filters to allow users to explore sales performance based on different business dimensions.
